Import from CSV

Paste your data below, first row as headers. Works with a plain spreadsheet or a direct export from MFL itself.
Recognized columns (any order, only name and buy price are required):
name / player id / buy price / buy date / sold (yes/no) / sale price / sale date / batch (agency/group name)
Sale price should be the gross/listed price — MFL's 5% fee is deducted automatically when calculating P/L.
MFL exports work directly — firstName/lastName combine into name, id maps to player id, Value maps to buy price (not Price, which is a valuation, not cost), and joinedAgency maps to buy date. Rows with no Value logged (e.g. bulk/block-bought players) get skipped — add those as one lump entry yourself if you know the block price.
